# Подключение реальных моделей GLB

В проект включены две авторские модели автомобилей под [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/):

| Модель | Автор и исходная страница | Длина в сцене |
| --- | --- | --- |
| Chevrolet Onix | [uzb_rx7 (@uzbek_supra)](https://sketchfab.com/3d-models/chevrolet-onix-bfd798c2695847b28ab681d42abc7056) | 4.474 м |
| Chevrolet Cobalt LTZ 2014 | [Q.SARDOR (@qsardor57913)](https://sketchfab.com/3d-models/chevrolet-cobalt-ltz-2014-f91cbef731444f939e263041400216ca) | 4.479 м |

Для обеих моделей используются поворот −90° и равномерный масштаб. Актуальные файлы, ссылки, авторы и лицензии хранятся в `manifest.json`; сведения об изменениях опубликованы на [странице авторов](credits.html).

Слоты JAC J7 и конвейера содержат `null`. Скачанный AI-кандидат J7 не используется из-за искажённой геометрии; вместо него остаётся процедурное приближение J7. Конвейеры, роботы и оборудование детализированы процедурно, но не являются заводскими CAD-моделями Allur. Импортёр работает только с выбранным локальным файлом и ничего не скачивает.

## Что сейчас подключено к реестру

- **Onix и Cobalt по всей сцене**: кузова на производственных участках, готовые автомобили, маршруты ОТК и выезда, стоянка. `VehicleFleetProvider` объединяет совместимые части GLB и рисует повторяющиеся автомобили через GPU instancing.
- **Три уровня детализации автомобилей**: `url` — близкий план, `lodUrl` — средний, `distantUrl` — общий вид площадки. Оба облегчённых файла получены из того же авторского автомобиля. Переключение зависит от расстояния и настройки качества и использует разные пороги приближения/удаления, чтобы не мигать на границе.
- **Слот напольной секции конвейера в линии C** пока пуст. Для него нужен модуль соответствующего реального оборудования. Высокий складской ленточный конвейер для этой точки не подходит.

При подготовке удалены дублирующие узлы и избыточные вершины, созданы упрощённые производные. Авторские PBR-карты сохранены; материал кузова клонируется для цвета автомобиля и стадии производства. У Cobalt дополнительно скорректированы шероховатость, металличность и лак. Центры колёс выделены в самостоятельные группы: вращение зависит от реального перемещения, при остановке оно прекращается. Стёкла, колёса и навесные детали показываются по мере сборки; эта анимация не является заводской CAD-моделью незавершённого кузова.

Для другого GLB нужно проверить распознавание кузова, стёкол, деталей и колёс. Единая текстурированная оболочка без разделения не выдаётся за последовательные стадии сборки. При незаполненном слоте, недоступном GLB, ошибке пропорций или за предельной дальностью остаётся лёгкая локальная геометрия.

Географические контуры корпуса и соседних зданий взяты из OpenStreetMap. Земля, покрытия, дороги, контейнеры и озеленение построены в сцене; спутниковая фотография не рендерится как поверхность. Подъезды и благоустройство — иллюстративная реконструкция, не результат геодезической съёмки.

## Перед импортом

Проверьте поколение и тип кузова автомобиля, форму деталей и пропорции. Название файла и запись `--kind onix` не подтверждают, что внутри действительно Onix. Для конвейера нужны файл или чертежи соответствующего оборудования; библиотечный объект нельзя выдавать за точную модель Allur.

Убедитесь, что лицензия разрешает использование и распространение файла в веб-приложении. Сохраните ссылку на оригинальную страницу, имя автора и точное название лицензии. Поля в манифесте хранят эти сведения, но не проверяют подлинность модели или права на неё.

Экспортируйте **glTF 2.0 Binary (`.glb`)**: Y вверх, все текстуры и буферы внутри файла, без декораций и подложки. Направление машины после `--rotation-y` должно быть **+X**. Импортёр принимает угол в **градусах**, а манифест хранит его в **радианах**. Сцена равномерно масштабирует модель по указанной длине и центрирует её.

- Длина Onix по умолчанию — **4.474 м**, Cobalt — **4.479 м**, J7 — **4.772 м**. Для автомобиля после масштабирования ожидаются ширина **1.4–2.4 м** и высота **1.1–2.1 м**.
- Для секции конвейера `--length` обязателен и не больше **12.8 м**. После масштабирования ожидаются ширина **2.2–3.2 м**, высота не больше **0.35 м**. В сцене верх секции выравнивается по высоте **0.30 м**. Эти пропорции дополнительно проверяются при загрузке модели.
- Максимум **64 MiB** на GLB; **500 000 треугольников** для автомобиля, **150 000** для конвейера. Учитываются повторения мешей в узлах и GPU instances. Для общего плана желательно значительно меньше.
- Поддерживаются обычная геометрия и Meshopt, PNG/JPEG/WebP/AVIF. Draco и KTX/Basis не подключены: экспортируйте без них. Внешние URL и относительные пути к текстурам/буферам запрещены; встроенные `data:` URI разрешены.

## Проверка без изменений

Из каталога `frontend`:

```sh
node scripts/install-glb.mjs --kind onix --file '/полный/путь/onix.glb' --check
```

Это проверяет структуру GLB, встроенные ресурсы, поддерживаемые обязательные расширения и бюджет геометрии. Команда не создаёт файлы, не меняет манифест и не требует сведений об авторе. Это структурная проверка, а не полный glTF Validator: качество, корректность текстур, ориентацию и соответствие реальному объекту нужно проверять в сцене.

## Импорт

Шаблон ниже **не указывает на готовый скачанный ассет**. Замените путь и три поля происхождения фактическими данными с оригинальной страницы выбранной модели:

```sh
node scripts/install-glb.mjs \
  --kind onix \
  --file '/полный/путь/chevrolet-onix.glb' \
  --rotation-y 90 \
  --source 'https://example.com/replace-with-original-asset-page' \
  --author 'ЗАМЕНИТЕ: имя автора с оригинальной страницы' \
  --license 'ЗАМЕНИТЕ: точная лицензия выбранного файла'
```

Угол `90` — пример; выберите его по фактическому направлению исходной модели. Для конвейера используйте `--kind conveyor --length 6`, если реальная длина выбранного модуля равна 6 м. Доступны также `npm run models:install -- ...` и `node scripts/install-glb.mjs --help`.

После успешной проверки файл копируется под именем вида `onix-<hash>.glb`, затем атомарно обновляется `manifest.json`. Другие слоты сохраняются. Заполненный слот не заменяется без `--replace`; при замене старый GLB сохраняется. Если запись манифеста была прервана, возможен неиспользуемый GLB, но действующий манифест остаётся целым. Одновременные импорты блокируются файлом `.install-glb.lock`.

Импортёр не создаёт LOD автоматически. Для автономной подготовки используются `scripts/dedupe-vehicle.mjs`, `scripts/optimize-vehicle.mjs` и отдельная настройка Cobalt в `scripts/optimize-cobalt.mjs`. Производные сохраняются в отдельные файлы и проходят визуальную проверку; `lodUrl` и `distantUrl` должны указывать на версии того же автомобиля с совместимым разделением частей. Оригинальные скачанные файлы не перезаписываются.

Перезагрузите страницу: реестр считывается один раз при запуске. Кнопка **«Рассмотреть Onix»** показывает автомобиль крупным планом и сопровождает его по демонстрационному маршруту ОТК; из сценариев производства она возвращает в этот режим. Ручное вращение или масштабирование останавливает сопровождение. Можно также открыть ОТК, включить высокое качество и приблизить камеру самостоятельно. Если файл не загрузился или не прошёл проверку пропорций, сцена сохраняет исходную геометрию. Чтобы отключить модель, установите соответствующий слот в `null` и перезагрузите страницу.

## Проверки моделей

```sh
npm run models:test
```

Проверяются импорт, нормализация, колёса, группировка частей и соответствие LOD производственным стадиям. Тестовые GLB импортёра создаются во временных каталогах; они не становятся моделями проекта.
